# 云航导航（aether-nav）需求文档

> 文档版本：v1.0 · 整理日期：2026-08-09 · 状态：随实现同步更新
> 配套设计文档：[权限模型设计.md](./权限模型设计.md)（四层权限 / 用户维度 / 链接维度 / 审计 / 统计）

---

## 1. 产品定位

自托管的书签 / 导航面板，统一管理**外网**与**内网**服务入口。面向小团队或家庭场景：
- 一个可定制的主页卡片墙，按「内网 / 外网」切换视图；
- 细粒度的链接可见性（按用户、角色、公开、私有）；
- 管理员集中维护分类与链接，普通成员按权限浏览并管理自己创建的链接；
- 内置搜索、天气、数据统计与权限审计，离线/内网可用（字体与图标本地化）。

技术栈：**Flask + SQLAlchemy + SQLite**（后端）/ **Vue 3 + Vite + Tailwind**（前端），零外部 CDN 依赖。

---

## 2. 角色与权限模型（摘要）

角色 `role` ∈ {`admin`, `member`, `guest`}；账号可被禁用（`is_active=False` → 无法登录、看不到任何链接）。

| 角色 | 主页浏览 | 链接管理 | 分类管理 | 用户/审计/设置/统计 |
|------|---------|---------|---------|-------------------|
| 管理员 admin | 全部可见（受分类墙约束） | 全部可编辑 | 增删改 + 角色墙 | 全部可用 |
| 普通成员 member | 有权限的链接 | 可访问；**自身链接可编辑**，他人链接仅可设访问密码 / 主页显隐 | 可**新增**分类，**不可修改/删除** | **不可见**（菜单自动隐藏） |
| 访客 guest | 仅「权限=所有人」的链接；加密链接需输入密码 | 无 | 无 | 无 |

可见性判定见[权限模型设计.md](./权限模型设计.md) 的四层模型（账号墙 L0 → 分类隐藏/角色墙 L1 → 链接基础权限 L2 → 显式授权/拒绝 L3）。

## 3. 功能需求

### 3.1 导航主页（Home）
- **卡片墙**：分类卡片 + 链接卡片，桌面端网格（列数可在系统设置调节 2–8），移动端方形卡（`SquareCard`）。
- **内网 / 外网切换**：顶部网络模式切换；链接按 `network` 字段（external/internal）过滤展示。
- **拖拽排序**：管理员可在系统设置开关「主页卡片拖拽排序」（`drag_sort_enabled`），开启后用户可拖拽排序主页卡片，排序按用户独立保存（link order 表）。
- **加密链接**：带密码的链接打开前弹出 `PasswordModal` 校验；主页可显示锁角标（系统设置「显示密码锁标识」控制）。
- **点击埋点**：每次打开链接异步上报 `AccessLog`（不阻塞跳转）。
- **天气组件**：顶栏 `WeatherWidget` 显示当前天气（本地组件）。

### 3.2 分类管理
- 二级分类树，支持新增 / 修改 / 删除 / 排序（上下移）。
- 每个分类：`visible`（主页全局显示开关）、`archived`（归档/回收站）、`owner_id`、`allowed_roles`（角色白名单）。
- **角色白名单**：仅管理员可设置「该分类仅哪些角色可见」，空 = 全员可见。
- **主页显隐**：分类「不在主页显示」对所有用户（含管理员）生效，覆盖任何单独授权。
- 普通成员**只能新增**分类，不能修改或删除（含自己创建的）。

### 3.3 链接管理
- 链接字段：标题、内网 URL、外网 URL、描述、图标、分类、基础权限 `permission` ∈ {`all`, `registered`, `admin`, `self`}、所有者 `owner_id`、活跃状态 `is_active`、访问密码。
- 新增链接：支持手动表单（`AddLinkModal`）与**快速添加**（`QuickAddLink`，粘贴地址自动识别内外网并填 URL）。
- 图标：自动抓取 favicon / 本地上传（`EntityIcon` + `IconPicker`）；管理员与链接添加人可改；支持自定义图标 URL 与文字图标。
- 链接显隐开关：是否展示在用户主页（按查看者个人生效，见 3.4）。
- 删除：仅 `can_edit` 的链接显示删除按钮（管理员或所有者）。

### 3.4 权限与可见性
- **四层模型**（见设计文档）：账号墙 → 分类隐藏/角色墙 → 链接基础权限 → 显式授权/拒绝。
- **用户维度权限编辑**（管理员）：`PermissionEditModal` 双页签
  - 可管理链接：单开关（开=可见，关=对该用户隐藏），顶栏「恢复默认」一键全开；保存仅传 `denies`。
  - 无权限链接（只读）：列出该用户最终不可见链接，标注被哪一层拦截（L0/L1a/L1b/L2/L3）及原因；仅 L3 可在上一页签开启。
- **链接维度权限矩阵**（管理员）：`LinkPermissionMatrixModal`，以链接为中心展示每个用户的最终可见性与拦截原因。
- **按用户主页显隐**：`UserLinkVisibility`，每个查看者对个人主页是否展示某链接独立开关。
- **按用户独立访问密码**：每个用户可为「他人分享给自己的链接」设置自己的访问密码（`set_user_link_password` / `clear_user_link_password`）；普通成员在链接管理页可改（仅密码字段，其余字段 403）。

### 3.5 后台管理（管理员）
- 入口 `/admin`，侧边导航 6 项：链接管理 / 分类管理 / 用户管理 / 权限审计 / 系统设置 / 数据统计。
- **用户管理**：角色变更、启用/禁用、删除；密码重置入口。
- **权限审计**：`AuditLog` 时间线（权限拒绝/恢复、链接权限变更、分类变更、用户角色/封禁、注册、设置变更），支持按动作筛选 + 分页。
- **数据统计**：见 3.9。

### 3.6 普通用户后台权限（最新）
- 普通成员可访问「链接管理」「分类管理」两个页面；其余管理页（用户/审计/设置/统计）在侧边栏**直接不显示**，且误入时自动回退到「链接管理」。
- **分类**：允许新增，不允许修改/删除。
- **链接管理**：仅展示用户有权限访问的链接；
  - 自己添加的链接：标题、URL、描述、图标、分类、权限等**全部可编辑**；
  - 他人添加的链接：编辑弹窗字段**只读**，仅可设置「访问密码」与「是否在主页显示」。
- 头像菜单对所有登录用户一致（均显示「个人设置」「管理后台」），不区分角色。

### 3.7 系统设置（管理员，单卡片三列布局，铺满页面）
- **左列 · 账号与安全**：开放注册开关、新用户默认角色、登录令牌有效期（小时）、访问日志保留天数、局域网网段（CIDR 自定义，用于快速添加识别内外网）。
- **中列 · 主页管理 / 主页入口 / 网络模式 / 密码锁标识**：
  - 允许主页内容编辑（用户自定义主页）；
  - 显示「个人设置」入口、显示「管理后台」入口（仅管理员生效）；
  - 默认网络（内网 / 外网）；
  - 显示密码锁标识（带密码链接的角标）。
- **右列 · 显示 / 外观 / 搜索**：
  - 每行显示列数（2–8）、紧凑模式、卡片密度（舒适/紧凑）；
  - 界面主题（浅色/深色/跟随系统）；
  - 默认主搜索引擎、新标签页打开、搜索框位置（固定/滚动）。

### 3.8 账号与安全（站点级开关）
复用 `Setting` 表，由管理员在系统设置配置：
- `allow_register`（默认 true）：关闭后 `/api/auth/register` 返回 403。
- `default_role`（默认 member）：自助注册用户自动获得的角色。
- `token_max_age_hours`（默认 168）：登录令牌有效期。
- `log_retention_days`（默认 90）：`AccessLog` 惰性清理超期记录。
- 安全相关变更写入审计日志（`setting_update`）。

### 3.9 数据统计（数据统计页，零依赖原生 SVG 图表）
聚合接口（均 admin 鉴权），前端 `StatsView` 展示：
- KPI：总用户 / 近 7 日活跃 / 总点击 / 今日点击 / 今日登录；
- 趋势折线：点击/登录双线（7/30/90 天可切换）；
- 角色分布环形图；
- 热门链接 TOP10、活跃用户 TOP10、热门分类 TOP10（条形）。
- 数据来自 `AccessLog`（点击埋点 + 登录事件），非管理员访问返回 403。

### 3.10 权限审计（`AuditLog`）
- 模型：`operator_id, action, target_type, target_id, target_name, detail, created_at`。
- 写入点（不影响主流程，失败静默）：权限拒绝/恢复、链接权限变更、分类变更、用户角色/封禁、注册、设置变更。
- 查看：`GET /api/admin/audit` 倒序分页 + 动作筛选。

### 3.11 移动端
- 底部固定导航（`MobileNav`）：首页 / 分类 / 搜索 / 我的；**不显示「添加」按钮**（添加仍用顶栏「+」）。
- 侧边抽屉（`Sidebar`）：点「我的」或顶栏菜单图标滑出 280px 抽屉，内部分类树可滚动（`min-h-0` 修正），底部含主题切换、个人设置、退出登录。
- 卡片标识：移动端卡片右上角小圆点代表网络（外网=绿 `bg-success`、内网=蓝 `bg-info`）；若显示锁角标则置于右下角，且为桌面尺寸的 50%。
- 主内容滚动区底部留白（`pb-20 lg:pb-0`），避免被固定底栏遮挡。

### 3.12 主题与外观
- 浅色 / 深色 / 跟随系统；CSS 变量主题（`rgb(var(--c-*)/<alpha-value>)`），`darkMode:'class'`。
- 玻璃卡片等全局样式本地化，离线可用。

### 3.13 搜索
- 首页搜索框：站内搜索 + 可选外部引擎（Google/DuckDuckGo/Bing/Brave/Baidu）。
- 默认引擎、新标签页打开、搜索框位置（固定/滚动）可在系统设置配置。
- 访客可使用站内搜索。

### 3.14 认证与账户
- 登录（Bearer Token，有效期受 `token_max_age_hours` 控制）。
- 自助注册（受 `allow_register` 控制）；注册可选默认角色。
- 个人设置页（`ProfileView`）：修改个人信息 / 密码。
- 重置密码流程（`ResetPassword.vue`）、注册页（`Register.vue`）。
- 头像菜单（`UserMenu`）：所有登录用户一致，含「个人设置」「管理后台」。

### 3.15 图标
- 自动抓取目标站 favicon；本地上传覆盖；自定义图标 URL；文字图标。
- 图标组件 `EntityIcon` 统一渲染；`IconPicker` 选择/上传。
- 字体（Inter）与图标（Material Symbols）通过 `@fontsource` 本地化打包，不依赖 Google Fonts CDN。
